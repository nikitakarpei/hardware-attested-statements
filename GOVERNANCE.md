# Governance

Maintainer: Nikita Karpei (nikitakarpei@mailbox.org).

Maintainers review and merge pull requests, decide spec changes, approve releases and handle security reports.
They use two-factor authentication. Decisions are made in issues and pull requests; when there's no agreement, a
maintainer decides and says why. Contributors with sustained, careful contributions can be invited to become
maintainers.

If no maintainer acts for 90 days, treat the project as unmaintained: it gets no security fixes, and its license
lets anyone fork it.
